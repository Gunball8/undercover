Party Game — Configurable

Choisis #Citizens / #Undercover / #Mr White, et le jeu s'adapte (multi-rounds jusqu'à victoire).

Comment jouer ?

1. Chacun regarde son mot en privé. Les Citizens ont le même mot, l'Undercover un mot proche (sans le savoir), Mr White n'a rien.

2. À tour de rôle, chacun donne un indice court sur son mot : assez clair pour les alliés, assez flou pour ne pas se faire griller.

3. Débat, puis vote : le groupe élimine un suspect. Si Mr White est éliminé, il peut deviner le mot → victoire instantanée.

4. Citizens gagnent en éliminant tous les imposteurs. Les imposteurs gagnent en survivant jusqu'à la parité.
